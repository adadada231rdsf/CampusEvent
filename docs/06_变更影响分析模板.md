## 1. 为什么先做这份模板

变更适应能力（30 分）考察的不是“改得快”，而是“改之前能说清楚会影响什么”。因此先在 baseline-v1 上量出基线：

| 基线指标 | baseline-v1 实测 |
| --- | --- |
| 业务代码规模 | 域层 7 个文件 701 行 + 装配层 262 行；模板 9 个 171 行 + CSS 275 行 |
| 测试规模 | 5 个文件、65 条用例（0 失败，2.69 s） |
| 核心业务类 | `RegistrationService`、`ActivityService`、`RegistrationPolicy`（及 2 个子类）、`NotificationService` |
| 扩展点 | 策略注册表 `_POLICIES`、通知 `register(channel)`、`stats()` 字段集合 |
| Git 标签 | `baseline-v1` |
| 已知的技术债 | 认证仅演示账号；SQLite 单机；无候补与名额扩容 |
